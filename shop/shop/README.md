# 아바타 · 상점 (app/shop)

러너 위치에 3D 아바타를 보여주고, 러닝코인으로 꾸밈 아이템을 사서 입히는 기능이에요.
다른 기능과 분리된 폴더라서 이 폴더만 고치면 되고, 폴더를 지워도 앱은 그대로 동작해요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `items.js` | **부위(분류) · 상품 · 가격 · 코인 충전 상품** 데이터. 상품을 늘릴 때 여기만 고치면 됨 |
| `wallet.js` | 코인 잔액 · 보유 아이템 · 착용 상태 저장 (지금은 휴대폰 localStorage) |
| `avatar3d.js` | three.js 3D 사람 + 달리기 동작 + 헤어·옷·신발·악세사리 모양 |
| `thumbs.js` | 상품 카드 사진 자동 생성 (3D 아바타에 그 상품을 입혀서 그 부위를 찍음) |
| `shop-ui.js` | 상점 창, 코인 잔액, 3D 미리보기, **입어보기**, 부위별 탭, 상품 카드, 코인 충전 창 |
| `shop.css` | 위 화면들의 스타일 |
| `index.js` | 지도 위 내 마커에 아바타 붙이기 + 상점 화면 만들기 |
| `loader.js` | `index.html` 에서 부르는 한 줄짜리 입구 (CSS와 나머지 코드를 받아옴) |

`index.html` 에 들어간 것은 딱 두 줄이에요: `<script src="shop/loader.js">` 와 `window.Shop?.init(map, state)`.

## 쓰는 법

- 홈 시트의 **🛍️ 아바타 상점** 줄을 누르면 상점 창이 열려요.
- **상품 사진을 누르면 입어보기** — 위쪽 3D 미리보기에만 입혀져요 (코인 안 듦, 지도 위 아바타는 그대로).
  여러 개를 섞어서 입어볼 수 있고, 미리보기 아래 막대에서
  - **원래대로**: 입어보기 취소
  - **🪙 ○○ 구매하고 입기**: 안 가진 건 한 번에 사고, 가진 건 그대로 입음 (코인이 모자라면 충전 창이 열림)
- 미리보기는 **옆으로 밀면 돌아가고**, **탭하면 달리는 모습**이 나와요.
- 카드 아래 버튼은 그대로 **구매 / 착용 / 착용 중 · 해제** 예요.
- 상점을 닫으면 입어보던 것은 초기화돼요.
- 맨 위 **내 러닝코인** 칸을 누르면 코인 충전 창 (데모: 실제 결제 없이 바로 지급).

## 부위와 자리

| 탭 | 자리 | 같이 입을 수 있나 |
|---|---|---|
| 헤어 | `hair` | 하나만 |
| 상의 | `top` | 하나만 |
| 하의 | `bottom` | 하나만 |
| 신발 | `shoes` | 하나만 |
| 악세사리 | `acc-head` (모자·바이저·헤어밴드), `acc-face` (선글라스), `acc-back` (백팩·조끼), `acc-wrist` (시계) | **자리가 다르면 같이 착용** (모자 + 선글라스 + 조끼 + 시계) |

악세사리의 자리는 `look.type` 으로 자동으로 정해져요 (`items.js` 의 `ACC_SLOT`).

## 자주 하는 수정

**상품 추가** — `items.js` 의 `ITEMS` 에 한 줄 추가 (`id` 는 겹치면 안 되고 한 번 정하면 바꾸지 않기).
이미 있는 모양(style/type)에 색만 바꿔서 넣으면 사진·3D 모두 자동으로 만들어져요.
```js
{ id: "top-tee-red", name: "레드 티셔츠", desc: "기본 반팔 러닝 티", category: "top", price: 800, image: "", look: { style: "tee", color: "#d63a2f", accent: "#ffffff" } },
```

**쓸 수 있는 모양**

| 부위 | look |
|---|---|
| 헤어 | `style`: `short` 숏컷 · `ponytail` 포니테일(달릴 때 흔들림) · `bun` 번 · `bob` 단발 · `curly` 펌 / `color` |
| 상의 | `style`: `tee` 반팔 · `singlet` 싱글렛(배번표) · `long` 긴팔 · `jacket` 바람막이 · `stripe` 줄무늬 / `color`, `accent` |
| 하의 | `style`: `shorts` 반바지 · `half` 5부 타이츠 · `long` 레깅스(accent 있으면 옆선) · `jogger` 조거 / `color`, `accent` |
| 신발 | `style`: `daily` 데일리 · `trail` 트레일(밑창 두꺼움) · `racer` 카본 레이서(밑창 가장 두꺼움) / `color`, `sole`, `accent` |
| 악세사리 | `type`: `cap` · `visor` · `headband` · `glasses` · `backpack` · `vest` · `watch` / `color`, `accent` |

`accent` 는 포인트 색 (줄무늬, 지퍼, 목 테두리, 모자 챙, 렌즈 테, 물병, 시계 화면 등).

**상품 사진 직접 넣기** — `image: "shop/img/파일.png"` 처럼 주소를 넣으면 자동 사진 대신 그 사진이 나와요.

**카드 사진 구도 바꾸기** — `thumbs.js` 의 `VIEWS` (부위별 카메라 위치·거리·각도).

**새로운 모양 만들기 (예: 목도리)** — `avatar3d.js` 에서
1. "몸 만들기" 부분에 그룹을 만들어 붙이고 (`group(put(모양, 재질, x, y, z), ...)`)
2. `setLook()` 에서 `type === "scarf"` 일 때 `visible = true`
3. 악세사리면 `items.js` 의 `ACC_SLOT` 에 자리 추가 (예: `scarf: "acc-neck"`) + `SLOT_LABEL` 에 이름 추가

**미리보기 크기** — `index.js` 의 `createPreview` (`width`, `height`, `dist`: 카메라 거리) 와 `shop.css` 의 `.sp-preview`.

**러닝 보상으로 코인 주기** — 러닝이 끝나는 곳에서 `window.Shop?.addCoins(50)` 을 부르면 돼요 (아직 연결 안 함).

**코인 충전 금액 바꾸기** — `items.js` 의 `COIN_PACKS`.

## 알아둘 점

- 지금은 **데모**예요. 코인·구매 기록이 이 휴대폰에만 저장되고, 누구나 브라우저에서 값을 바꿀 수 있어요.
  실제 돈을 받으려면 결제 서비스(PG) 연동과, 결제 확인 후 **서버에서** 코인을 지급하는 방식으로 바꿔야 해요
  (`shop-ui.js` 의 `spPay` 클릭 부분과 `wallet.js` 를 서버 연동으로 교체).
- 예전 임시 상품(`item1`~`item5`, "상품1~5")은 없어졌어요. 그걸 샀던 기록은 자동으로 정리되고, 코인은 돌려주지 않아요.
- 3D 는 three.js 를 CDN(unpkg)에서 받아와요. 못 받거나 WebGL 이 안 되면 기존 라임색 원 아이콘이 그대로 보이고, 상품 카드는 빈 칸이에요.
- 카드 사진은 상점을 열 때 한 장씩 만들어서 기억해 둬요 (앱을 다시 열면 다시 만듦, 27개 기준 1~2초).
- 배터리를 아끼려고 지도 위 아바타는 서 있을 땐 다시 그리지 않고, 달릴 때만 초당 30프레임으로 그려요.
