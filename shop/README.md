# 아바타 · 상점 (app/shop)

러너 위치에 3D 아바타를 보여주고, 러닝코인으로 꾸밈 아이템을 사서 입히는 기능이에요.
다른 기능과 분리된 폴더라서 이 폴더만 고치면 되고, 폴더를 지워도 앱은 그대로 동작해요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `items.js` | **부위(분류) · 상품 · 가격 · 코인 충전 상품** 데이터. 상품을 늘릴 때 여기만 고치면 됨 |
| `wallet.js` | 코인 잔액 · 보유 아이템 · 착용 상태 저장 (지금은 휴대폰 localStorage) |
| `avatar3d.js` | three.js 3D 사람 + 달리기 동작 + 착용 상품 반영 |
| `shop-ui.js` | 상점 창, 코인 잔액, 부위별 탭, 상품 카드, 코인 충전 창 |
| `shop.css` | 위 화면들의 스타일 |
| `index.js` | 지도 위 내 마커에 아바타 붙이기 + 상점 화면 만들기 |
| `loader.js` | `index.html` 에서 부르는 한 줄짜리 입구 (CSS와 나머지 코드를 받아옴) |

`index.html` 에 들어간 것은 딱 두 줄이에요: `<script src="shop/loader.js">` 와 `window.Shop?.init(map, state)`.

## 쓰는 법

- 홈 시트의 **🛍️ 아바타 상점** 줄을 누르면 상점 창이 열려요.
- 상점 맨 위 **내 러닝코인** 칸을 누르면 코인 충전 창이 열려요 (데모: 100코인 1,000원 / 1,000코인 10,000원 / 10,000코인 100,000원, 실제 결제 없이 바로 지급).
- 구매하면 바로 입혀지고, 이후엔 **착용 / 착용 중 · 해제** 로 바꿀 수 있어요.
- 상점 안 미리보기를 누르면 달리는 모습이 나와요.
- 달릴 때는 지도 위 내 위치의 아바타가 같이 달려요.

## 자주 하는 수정

**상품 추가** — `items.js` 의 `ITEMS` 에 한 줄 추가 (`id` 는 겹치면 안 되고 한 번 정하면 바꾸지 않기).
```js
{ id: "item6", name: "빨간 모자", category: "head", price: 1500, image: "shop/img/cap-red.png", look: { type: "cap", color: "#d00" } }
```

**상품 사진** — `image` 에 주소를 넣으면 카드에 사진이 나와요. 비워두면 빈 칸이에요.

**아바타에 보이는 모습(`look`)**
- `head`: `{ type: "cap", color }`
- `top` / `bottom` / `shoes`: `{ color }` (옷·신발 색이 바뀜)
- `acc`: `{ type: "backpack" | "glasses", color }`

새로운 모양(예: 목도리)은 `avatar3d.js` 의 `setLook()` 과 몸 만드는 부분에 추가하면 돼요.

**러닝 보상으로 코인 주기** — 러닝이 끝나는 곳에서 `window.Shop?.addCoins(50)` 을 부르면 돼요 (아직 연결 안 함).

**코인 충전 금액 바꾸기** — `items.js` 의 `COIN_PACKS`.

## 알아둘 점

- 지금은 **데모**예요. 코인·구매 기록이 이 휴대폰에만 저장되고, 누구나 브라우저에서 값을 바꿀 수 있어요.
  실제 돈을 받으려면 결제 서비스(PG) 연동과, 결제 확인 후 **서버에서** 코인을 지급하는 방식으로 바꿔야 해요
  (`shop-ui.js` 의 `spPay` 클릭 부분과 `wallet.js` 를 서버 연동으로 교체).
- 3D 는 three.js 를 CDN(unpkg)에서 받아와요. 못 받거나 WebGL 이 안 되면 기존 라임색 원 아이콘이 그대로 보여요.
- 배터리를 아끼려고 아바타는 서 있을 땐 다시 그리지 않고, 달릴 때만 초당 30프레임으로 그려요.
